# Release 0.3.3

Package: History for Spotify Web 0.3.3. Source: Tampermonkey userscript 0.3.3; `extension/history.js`, `extension/history.css`, and `extension/i18n.js` are generated by `scripts/build.py`.

## Behavior

History options in the page and browser popup offer Player bar, Floating button, and Top bar. Player bar is the default. Player and floating controls are icon only. The top-bar control retains its text and count, stays outside the avatar wrapper, and preserves native Spotify controls. Crowded or unavailable locations use the floating clock.

The selected position is stored locally with the existing history and limit settings. English, Spanish, and Brazilian Portuguese are supported. Existing history keys, retention, and permissions are unchanged.

## Verified

The standard browser suite passes 375 checks in headless Chrome. It covers recording, persistence, exact track links, search, Queue automation against fixtures, JSON backups, retention, row menus, dragging, localization, button positions, native-control geometry, keyboard focus, preference persistence, and page/popup synchronization. It also loads the actual unpacked Manifest V3 extension and checks Spotify-only injection and the disconnected popup state.

Additional local capture checks use the supplied player-bar screenshot as a visual reference. Player, floating, top-bar, narrow-window, and localized settings were rendered and inspected. These local reference images are not included in the public release.

The package validator checks manifest scope, source parity, translation catalogs, icon dimensions, and every ZIP entry. JavaScript and publishing-shell syntax checks pass.
